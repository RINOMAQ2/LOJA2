Rinomaq Entregas - versão estática sem npm

COMO SUBIR:
1. Extraia o ZIP.
2. No GitHub, envie APENAS estes arquivos na raiz:
   - index.html
   - RINOMAQ.jpg
   - README.txt
3. Não precisa package.json. Não precisa npm. A Vercel não vai rodar npm install.
4. Na Vercel, importe o repositório e clique Deploy.
